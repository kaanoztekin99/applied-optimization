# applied-optimization-lab2


All solutions and implementations used in the report are provided in this repository.
The lab was completed entirely in Python.

- The `figures/` directory contains all contour plots and visualizations generated during the KKT analysis.
- The `scripts/` directory includes the complete Python implementations for each optimization problem.
- Problems 1–4 are implemented within a single script due to their similar structure, while the remaining problems are solved in separate scripts for clarity and modularity.
- All figures referenced in the report are generated directly from the corresponding scripts and saved under the `figures/` directory.
